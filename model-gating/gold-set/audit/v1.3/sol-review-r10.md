The rule I would freeze is:

1. **Apply `match` first.** Equality after conventional rounding to the printed precision is `match`. Preserve the distinction between a printed point value and a printed inequality. Select the scoring reference using R5's same-claim, same-workflow provenance requirements; do not silently pool conflicting output versions.
2. **Require evidence of a reporting slip for deterministic `close`.** Identify a specific supported problem, such as truncation, digit/row transcription, or a source-identified typo. Numerical proximity and unchanged conclusions alone are insufficient. An unresolved difference involving samples, exclusions, inputs, or implementation is `discrepant`, unless it is actually `not_checkable` under the existing rules.
3. **For continuous quantities other than p values, retain R10's numerical ceiling:** absolute gap ≤ one unit of the last printed digit **or** relative gap ≤ 1%, in addition to item 2. Define relative gap as `abs(recomputed − reported) / abs(reported)`; disable that arm when the reported value is zero. Use the unrounded reference when available. For intervals, apply the ceiling to each endpoint separately. The ceiling limits a supported minor slip; it does not establish its cause.
4. **Treat counts as exact integers.** Neither the one-unit nor the relative arm excuses a count mismatch. A wrong count remains `discrepant`, P2 under R2. This is an explicit benchmark convention, including for a one-count error.
5. **For actual p values, disable the one-unit arm.** A nonmatching p value can be `close` only with the evidence in item 2, relative gap ≤ 1%, and no change in the inferential decision the paper makes. An absolute tolerance inherited from coarse decimal printing is unsafe near zero.
6. **Apply substantive vetoes before assigning `close`.** A sign reversal, change in whether an interval contains the null, false printed inequality, or crossing of a threshold used by the paper is `discrepant`, irrespective of the numerical ceiling or a possible typo. The inequality safeguard applies to every quantity, not only p values.
7. **Retain the unseeded stochastic exception**, supported by evidence about the analysis and its variation rather than numerical proximity alone. Preserve the existing G-16 and G-28 source-supported judgements; this review does not estimate new simulation-error bounds. Deterministic version differences do not automatically qualify for this exception.
